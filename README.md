A hand-sketched funeral for the "before GTA 6" meme: the classic mourners gather around its tombstone on a Vice City beach at sunset, Michael from GTA V has taken the old man's place, and make.fun's ghost officiates with the wreath. Posted on X by @zestnorthe; `POST.json` names the post and `main.ts` hands it to the grader. The caption text lives in `caption.txt`, the picture is the post's first picture on X, and the drawing experiments that led here are `draw_meme.py` (a hand-drawn funeral coded stroke by stroke) and `make_template_meme.py` (a classic-template composite).

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
